# WinSkitch v1.2.0

アプリ自身による更新の確認・取得・差し替えを追加しました。文字の移動と切り抜きの操作も改善しています。

## 自動更新

- 起動時と常駐中の6時間ごとに、GitHub Releaseの最新正式版を確認します。
- PCの種類に合ったZIPを自動取得し、SHA-256、EXEのバージョンとアーキテクチャを検証します。
- 準備ができると上部に「更新して再起動」を表示します。トレイ常駐中は通知します。
- ボタンから更新する際、画像を開いていれば保存を確認します。録画・キャプチャ中は更新できません。
- 現在と同じ場所のEXEを差し替えるので、保存履歴とスタートアップ登録を引き継ぎます。
- 差し替えに失敗した場合は旧版を保持し、新版を起動できない場合は旧版に戻します。
- 接続できない場合も通常の編集・キャプチャを続けられます。「更新を確認」から再試行できます。

v1.1.0以前には更新機能がないため、最初の一度だけ手動でこのバージョンのEXEへ置き換えてください。以降はGitHubに公開された新しい正式版をアプリから更新できます。インターネット接続と、EXEの保存先への書き込み権限が必要です。

## 操作の改善

- テキストツールのまま、確定済みの文字をドラッグして移動できます。再編集はダブルクリックです。
- 切り抜きの四隅に加えて四辺の中央にもハンドルを追加しました。縦幅・横幅だけを調整できます。
- EXEやショートカットを再度開いたとき、既存のウィンドウを復元し、前面表示の権限を引き継ぎます。
- メイン画面右上に「ログイン時に起動」を表示し、設定メニューとチェック状態を連動させました。

## 検証

自動テストは全51件が成功し、x64版の配布EXEの起動を確認しました。

更新のテストではGitHubへ接続せず、合成したRelease情報と専用テストフォルダーを使います。破損・中断・別バージョン・別アーキテクチャ・不正なZIP、書き込みロック、差し替え失敗と復元を確認します。実際のテストプロセスで、更新ヘルパーの準備完了、親プロセスの終了待ち、同じパスでの再起動も確認します。

ARM64版はクロスビルドで、ARM64実機での検証は未実施です。
