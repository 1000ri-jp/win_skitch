# WinSkitch v1.1.0

画面録画と保存履歴を追加しました。操作を MP4 動画で共有でき、保存した画像や動画の場所をアプリから開けます。

## 画面録画

- 範囲選択またはカーソルのあるモニター 1 台を録画できます。
- `Ctrl + Shift + 7` で範囲録画を開始・停止できます。上部の録画ボタン、「動画」メニュー、トレイからも操作できます。
- 保存先と範囲を選び、3 秒のカウントダウン後に開始します。操作パネルで経過時間を確認し、「停止して保存」で MP4 を確定します。
- マウスカーソルを含め、H.264 / MP4、15 fps、音声なしで保存します。Windows 標準の Media Foundation を使うため、追加ソフトのインストールは不要です。
- 録画・保存が成功するまで既存の保存先ファイルを保持します。保存先への移動に失敗した場合は完成した MP4 を一時ファイルに残し、回収できる場所をエラーに表示します。

## 保存履歴

- 上部の「履歴」または「ファイル」→「保存履歴…」から、保存した PNG / JPEG / MP4 を新しい順に最大 20 件確認できます。履歴は再起動後も残ります。
- 「保存先を開く」でエクスプローラーにファイルを表示します。ファイルが移動・削除済みでも、元のフォルダーが残っていれば開けます。
- 「ファイルを開く」で Windows の既定の画像アプリ・動画プレーヤーを起動できます。

## ダウンロードと更新

- 通常の Intel / AMD PC: `WinSkitch-v1.1.0-win-x64.zip`
- ARM64 PC: `WinSkitch-v1.1.0-win-arm64.zip`

ZIP を展開し、`WinSkitch.exe` を起動してください。使い方は同梱の `README.txt` にあります。.NET ランタイムや Python の事前インストールは不要です。配布 ZIP の SHA-256 は `SHA256SUMS.txt` で確認できます。

更新時は、起動中の WinSkitch をトレイの「終了」で閉じてから EXE を置き換えてください。EXE の保存場所を変えた場合は、新しい EXE を起動して「Windowsログイン時に起動」をオンにし直します。

## 検証と制約

自動テスト 41 件で、画像編集・保存、動画の生成とデコード、保存履歴、起動処理を確認しました。x64 ではテスト用ウィンドウの画面録画、色と上下の向き、録画操作パネルの除外、および配布 EXE の起動を確認しました。

ARM64 版はクロスビルドしており、実機の動作確認は未実施です。録画には Windows の Media Foundation と H.264 エンコーダーが必要です。音声・Web カメラの収録、WinSkitch 内での動画再生・注釈編集には対応していません。
